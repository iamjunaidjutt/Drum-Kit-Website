# Drum Kit Website

An interactive in-browser drum kit built with HTML, CSS, and vanilla JavaScript that plays realistic percussion sounds on keyboard presses and mouse clicks.

## What It Does

- Plays distinct drum sounds for 7 instruments (Tom 1–4, Snare, Crash, Kick Bass).
- Supports both mouse clicks and keyboard triggers (`w`, `a`, `s`, `d`, `j`, `k`, `l`).
- Plays audio dynamically using the HTML5 `Audio` constructor.
- Applies visual flash animations to active buttons on press.

## Tech Stack

- **HTML5**
- **CSS3** (Arvo font, custom button styling, CSS keyframe animations)
- **Vanilla JavaScript** (DOM query selectors, `addEventListener`, audio playback)

## How to Play

1. Clone this repository:
   ```bash
   git clone https://github.com/iamjunaidjutt/Drum-Kit-Website.git
   cd Drum-Kit-Website
   ```
2. Open `index.html` in your browser.
3. Click any drum button or press the corresponding keys on your keyboard (`W`, `A`, `S`, `D`, `J`, `K`, `L`).
